## 1. 扩展函数（extension/）

### 1.1 RxJava 扩展（Rx.kt）

| 函数 | 签名 | 用途 | 使用示例 |
|------|------|------|----------|
| `toSingle()` | `Callable<T>.toSingle()` | Callable/Future/Lambda 转 Single | `{ apiCall() }.toSingle()` |
| `toMaybe()` | `Callable<T?>.toMaybe()` | Callable/Future/Lambda 转 Maybe | `{ maybeNull() }.toMaybe()` |
| `filterIsInstance()` | `Observable<*>.filterIsInstance<R>()` | 按类型过滤 Observable | `obs.filterIsInstance<MyType>()` |
| `observeOnMain()` | `Subject<T>.observeOnMain()` | Subject 切换到主线程 | `subject.observeOnMain()` |
| `autoDispose(lifecycleOwner)` | `T.autoDispose(LifecycleOwner)` | 在 ON_DESTROY 时自动释放 | `.autoDispose(this)` |
| `autoDispose(viewModel)` | `T.autoDispose(ViewModel)` | ViewModel 清除时自动释放 | `.autoDispose(viewModel)` |
| `autoDispose(scope)` | `T.autoDispose(Scope)` | Koin Scope 关闭时自动释放 | `.autoDispose(scope)` |
| `retryWithDelay()` | `Observable/Single/Completable.retryWithDelay(times, delay, unit)` | 带延迟的重试 | `.retryWithDelay(3, 1, SECONDS)` |
| `subscribe(lifecycleOwner)` | `Observable<T>.subscribe(LifecycleOwner, onNext)` | 订阅并自动释放 | `obs.subscribe(this) { result }` |
| `subscribe(viewModel)` | `Observable<T>.subscribe(ViewModel, onNext)` | 订阅并随 ViewModel 释放 | `obs.subscribe(viewModel) { result }` |

## 3. Repository 基类（base/data/storage/）

| 基类 | 用途 | 适用场景 | 关键成员 |
|------|------|----------|----------|
| `Repository` | 基础状态管理 | 所有 Repository 的基类 | `errors` (PublishSubject), `loading` (BehaviorSubject), `isFresh`, `isNeverUpdated`, `update()`, `invalidate()` |
| `SimpleSingleItemRepository<T>` | 管理单个数据项 | 当前用户信息、单条配置 | `item` (BehaviorSubject<T>), `getItem(): Single<T>` |
| `SimpleCollectionRepository<T>` | 管理集合 | 相册列表、标签列表 | `items` (BehaviorSubject<List<T>>), `mutableItemsList`, `broadcast()` |
| `SimplePagedDataRepository<T>` | 分页数据 | 照片列表、搜索分页结果 | `pagingOrder`, `pageLimit`, `loadMore()`, `noMoreItems`, `isOnFirstPage` |
