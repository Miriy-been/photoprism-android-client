## 二、基础/通用模块

| 模块 | 包路径 | DI 模块 | 提供的核心能力 |
|------|--------|---------|---------------|
| api | `api/` | `RetrofitApiModule` | 所有 Retrofit API Service |
| base | `base/` | 无（纯抽象） | Repository 基类、Activity 基类、分页模型 |
| extension | `extension/` | 无（纯扩展函数） | Rx 扩展、View 扩展、Picasso 桥接等 |
| di | `di/` | `IoModules`, `EnvModule`, `LocaleModule`, `DateFormatModule` | HTTP Client、JSON ObjectMapper、Preferences、WorkManager |
| env | `env/` | `EnvModule` | 会话管理（SessionCreator）、连接参数 |
| db | `db/` | `DbModules` | Room AppDatabase、CachedMedia |
| featureflags | `featureflags/` | dev/release/playRelease | 功能开关 |
| util | `util/` | 无（纯工具类） | 通用工具（Throttle、ReactivePreferences、安全 CustomTabs 等） |
| view | `view/` | 无（纯视图组件） | ErrorView、ThemedSwipeRefreshLayout 等 |

## 三、API 服务清单

| Service | 文件 | 用途 | 关键接口 |
|---------|------|------|----------|
| `PhotoPrismAlbumsService` | `api/albums/` | 相册 CRUD | getAlbums, create, delete, addMedia, removeMedia |
| `PhotoPrismClientConfigService` | `api/config/` | 客户端配置 | getClientConfig |

| `PhotoPrismPhotosService` | `api/photos/` | 照片操作 | getGeo, batchEdit, updateFile, merge |
| `PhotoPrismSessionService` | `api/session/` | 会话认证 | createSession, checkSession |
| `PhotoPrismSubjectsService` | `api/subjects/` | 主题/人物 | getSubjects |
| `PhotoPrismUploadService` | `api/upload/` | 文件上传 | upload |

## 四、模块依赖规则

```
welcome → envconnection → gallery (主流程)
                              ├── viewer (点击照片)
                              │    └── slideshow (幻灯片)
                              ├── search (搜索配置)
                              ├── albums (相册管理)
                              │    └── gallery (单相册浏览)
                              ├── labels (标签浏览)
                              ├── people (人物选择)
                              ├── map (地图模式)
                              ├── import (导入文件)
                              ├── upload (上传文件)
                              ├── prefs (设置)
                              ├── ext (扩展系统)
                              └── sync (后台同步)

所有 Feature 可依赖: base, extension, util, di, env, api
Feature 之间禁止循环依赖
```
